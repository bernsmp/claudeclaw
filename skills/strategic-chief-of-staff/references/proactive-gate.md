# Proactive Gate

Use this before sending any unsolicited message.

## Default Rule

Silence is the default.

Do not send a message unless one of these is true:

- risk increased
- leverage appeared
- a decision is needed
- a relationship moved
- a contradiction became visible
- something changed that affects what Max should do next

## Hard No-Send List

Never send:

- all clear reports
- successful health checks
- "everything looks good"
- generic encouragement
- status with no implication
- information that does not change action

## Scorecard

Score each from 0-2.

- urgency
- novelty
- business impact
- actionability
- confidence

## Threshold

- `8-10` → send if concise
- `6-7` → send only if timing-sensitive
- `0-5` → do not interrupt

## Message Test

If the draft does not answer at least one of these, kill it:

- what should Max do now
- what should Max notice
- what should Max stop
- what changed
- why this matters now

## Compression Rule

One message should contain:

- one insight
- one reason it matters
- one next move

If it needs more, it is not ready.
